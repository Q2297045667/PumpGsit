# Java 版的四种静止姿势

在头顶有空间的平地上输入命令。默认按潜行键起身，再输一次同一条命令也可以。想看清翘腿和旋转，用 F5 切换到第三人称，或请另一名玩家站在侧面看。

| 命令 | 游戏里的样子 |
| --- | --- |
| `/lay` | 仰卧在方块表面。 |
| `/legsup` | 仰卧，双腿抬起。第一人称也能看见双腿。 |
| `/bellyflop` | 面朝下趴在原地。需要向前爬时用 `/crawl`。 |
| `/spin` | 玩家在原地持续旋转，身边有三叉戟激流效果。 |

这四个动作使用 Java 26.3（协议 777）的玩家模型。其他协议和基岩版玩家无法发起这些动作。在同一世界旁观时，只有支持这个协议的玩家能收到姿势模型。[客户端截图](客户端验证.md) · [坐下和爬行的用法](使用与配置.md)

## 外观和装备怎么查

1. 两人用 Java 26.3 站到同一块平地。让一人戴头盔、手持一把剑，依次做上表四个动作，每个保持两秒。另一人应能看见正确的朝向和装备，按 Tab 时名单里只出现一个本人。
2. 保持仰卧，换掉头盔或手里的剑。观察者走出服务器的模拟距离，再回到原地，应能看到躺着的玩家和换好的装备。也可以让观察者在玩家躺下后才进服。
3. 按潜行键起身。观察者应只看见一个站着的人，装备仍穿在身上，脚下的方块恢复原样。旁观模式能看见隐身本体的半透明轮廓，检查是否有多余装备时请用生存模式。

服务端为每个观察者单独显示一个玩家模型。仰卧和翘腿还会给观察者发一张临时床，地图里的方块没有被替换。Java 客户端收到床坐标时会把模型移到床边，所以插件只在模型首次出现时发床坐标，随后两次把模型移回座位表面。翘腿另用一个乘客表现屈膝。模型同步皮肤层、惯用手、缩放、护甲和手持物。[GSit 3.8.0 的姿势实现](https://github.com/Gecolay/GSit/blob/04b792026acf95b63f198691d85218a1023e2f92/mcv/v26_3/src/main/java/dev/geco/gsit/mcv/v26_3/model/Pose.java)

实机检查用的是离线身份。联网皮肤、披风和夜间鼾声仍需在对应环境里确认。Wasm 0.2 没有读取肩上鹦鹉的接口，姿势模型也就不会显示它们。
