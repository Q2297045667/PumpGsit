# Java 26.3 姿势与验收

在头顶有空间的平地上，用 Java 26.3 玩家执行以下命令。第二名玩家站在侧面，可以看到四种不同的动作。默认按潜行键起身，再次输入同一条命令也可退出。

| 命令 | 旁观者应看到什么 | 本次图形实测 |
| --- | --- | --- |
| `/lay` | 玩家仰卧，身体贴近支撑面 | 侧面可见平躺的人物。等待超过两秒，身体仍在方块上。 |
| `/legsup` | 玩家仰卧并屈膝抬腿 | 观察端看见两膝抬起。执行者第一人称也能看见双腿。 |
| `/bellyflop` | 玩家面朝下趴着 | 双客户端测试中能从旁边看到面朝下的身体和手臂。 |
| `/spin` | 玩家呈三叉戟激流姿势并持续转动 | 连续两帧中的人物朝向和环状效果发生变化。按潜行键后只剩站立的玩家。 |

## 测试环境与依据

本节记录独立仓库更名前的测试。所用 Pumpkin 插件元数据名为 `gsit`，客户端截图及各轮组件校验值见[客户端验证](客户端验证.md)。

- 2026-11-19，在独立测试目录启动 Pumpkin `e318ec5ff87bbd0d72feafe40d6b24f230a8b84a`，加载 `wasm32-wasip2` 产物。两个原版 Java 26.3 图形客户端分别操作和旁观，使用本地离线测试身份。游戏协议版本为 777。
- 另在 Paper 26.3 build 249（`1a995d6`）启用 GSit 3.8.0。用协议客户端在地面依次运行上表每条命令，再次输入同一命令退出。四次都收到虚拟玩家的资料、生成、姿势元数据和结束时的移除包。两种睡姿各收到一次带床坐标的元数据和两次返回座位表面的绝对坐标校正；举腿时多一个车辆和乘客关系。俯卧的姿势为 `SWIMMING`，旋转为 `SPIN_ATTACK`，同时设置自动激流标记。此项是原版运行与协议对照。图形观察的结果来自 Pumpkin。
- 对 Pumpkin 的独立协议客户端重复上述八次命令。每次进入都收到新的、未列入玩家列表的资料；每次退出均收到资料移除。平躺时仅首次姿势元数据带床坐标，之后两次校正延迟约 0.1、0.2 秒。宿主正常关服并保存世界。
- 另一次使用两个协议客户端。执行者戴钻石头盔、持铁剑躺下；旁观者后登录并进入范围。换成金头盔、钻石剑后，观察端收到虚拟玩家的两项新装备。旁观者移到 80 格外、再回到身边，依次收到移除和重新生成。同次测试确认宿主重新追踪实体后，插件会重新隐藏真实玩家的装备；起身后真实玩家恢复金头盔、钻石剑。执行者挥拳以及控制台执行 `/damage <玩家> 1` 时，旁观者收到发给虚拟玩家的主手挥动包和受击包。
- 用 Java 26.3 客户端自带的 `STREAM_CODEC` 分别解码模型资料（含测试纹理属性）、三种姿势元数据和睡姿坐标校正，检查输入字节全部消费以及解码后的动作、实体编号、坐标。客户端每次处理床坐标时都会把睡姿实体移到该方块；因此仅在各观察者首次看见实体时发送床坐标。曾出现的“第一次躺下后身体消失”已按此修正，并用上表的两客户端操作复核。

原版的四种动作、乘客关系、虚拟床和延迟位置校正见上游实现。[GSit 3.8.0 的 Java 26.3 Pose.java](https://github.com/Gecolay/GSit/blob/04b792026acf95b63f198691d85218a1023e2f92/mcv/v26_3/src/main/java/dev/geco/gsit/mcv/v26_3/model/Pose.java)

## 范围与差异

- 四个静止姿势面向 Java 26.3，其模型和外观字段使用该版本的网络格式。插件会拒绝其他 Java 协议和基岩版玩家发起这四个姿势。对于这些观察者，插件只保留宿主的骑乘关系，具体画面未在相应客户端实测。普通坐下与移动爬行另见使用文档。
- 服务端保留真实玩家和用于骑乘的座椅，每位符合范围和可见条件的 Java 观察者收到虚拟玩家。卧姿所用的床只发给相应观察者，底层地图方块维持真实状态。退出后插件移除虚拟实体并重新发送原方块、真实玩家的装备和可见标记。
- 模型沿用玩家名与宿主提供的皮肤属性，复制皮肤层、惯用手、缩放、主副手和四件护甲。无纹理的离线玩家使用与本人一致的默认皮肤选择。装备和换装已通过双客户端协议检查，穿戴举腿时的画面见[客户端验证](客户端验证.md)。在线签名皮肤、披风及夜间鼾声尚待图形或声音验收。Wasm 0.2 玩家接口没有左右肩鹦鹉的读取接口，模型不显示原版可转移到假人肩上的鹦鹉。

## 服主复验

1. 让两个相同 Java 版本的玩家进入同一处平地。执行者穿一件颜色明显的护甲，旁观者站到侧面。先观察站姿和外观，再逐项运行上表命令。
2. 每项保持至少两秒，转动视角，用 F5 切换执行者视角，再按潜行键。观察者应看见表中对应动作、随后恢复的真实玩家，以及同一件装备。按 Tab 检查虚拟玩家不会占据额外一行。
3. 执行者保持躺下，让另一人离开模拟距离再返回。新观察者应看见仰卧的玩家。起身后两端均应只见正常玩家，再次运行 `/lay` 应能重新仰卧。可再以在线皮肤、有隐身效果、主副手互换的玩家复查外观。
