# 在聊天或侧边栏里显示玩家状态

只在需要占位符时安装 [PumpkinPIE](https://github.com/Rennex07/PumpkinPIE)。支持 PIE 的插件可以把下面六个名字写进聊天格式、侧边栏或全息文字模板。它们返回小写的 `true` 或 `false`。

| 占位符 | 什么时候为 `true` |
| --- | --- |
| `%gsit_sitting%` | 玩家坐在 PumpGsit 的方块座位上。骑在另一名玩家头上不算。 |
| `%gsit_posing%` | 玩家正在仰卧、翘腿、俯卧或旋转。 |
| `%gsit_crawling%` | 玩家正在用 PumpGsit 爬行。 |
| `%gsit_toggle%` | 玩家开启了右键方块坐下。 |
| `%gsit_playertoggle%` | 玩家开启了右键玩家叠坐。 |
| `%gsit_crawltoggle%` | 玩家开启了潜行手势爬行。 |

后三项主要用于显示玩家的偏好。比如玩家开启了右键坐下，`%gsit_toggle%` 就是 `true`；实际能坐哪些方块，还要看权限和服务器配置。

## 进服试一下

1. 在控制台输入 `pie expansions`，找到 `%gsit%  from PumpGsit` 和上表六项。刚重载过 PIE 时，等约 30 秒再查一次。
2. 用有 `PumpkinPIE:use` 权限的玩家输入 `/pie parse sit=%gsit_sitting% crawl=%gsit_crawling%`。站着时会看到 `sit=false crawl=false`。
3. 在平地上输入 `/sit`，再解析同一句，结果应变成 `sit=true crawl=false`。如果这里正常，侧边栏却仍然显示原文，请检查侧边栏插件是否调用 PIE 并传入了玩家名。

## 在控制台查离线玩家

在占位符后面加冒号和玩家的完整 UUID。下面的命令请换成自己服务器上的 UUID。

```text
pie parse 点击坐下=%gsit_toggle:11111111-1111-4111-8111-111111111111%
```

指定 UUID 后，查询以这个玩家为准。玩家离线时，前三个动作都是 `false`，后三项照常读取保存的偏好，没有记录时取服务器默认值。控制台省略 UUID、UUID 写错或只给离线玩家名时，PIE 会保留原文。迁服后若同名玩家的偏好变了，先核对两台服务器记录的登录 UUID。[数据库与迁服](存储.md)

## 从其他插件调用

调用 PumpkinPIE 的版本 0 IPC，把下面的 UTF-8 JSON 发给 `PumpkinPIE`。例子中的 `Steve` 要在线。PumpGsit 注册的缓存策略是 `never`，下一次解析就能读到刚切换的姿势。PIE 用 `unresolved` 返回未替换的条目。[IPC 字段与返回格式](https://github.com/Rennex07/PumpkinPIE/blob/cc3f05035346326ae27e6675003856bdb6ed7bbe/docs/protocol.md)

```json
{"op":"set_placeholders","viewer":"Steve","text":"坐下=%gsit_sitting% 偏好=%gsit_toggle%"}
```

加载顺序、热重载和重启后的离线查询可用仓库里的 `pie_smoke` 复查。[运行方法](构建与验证.md#重跑验证) · [测试代码](../tests/support/smoke.rs)
